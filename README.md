# telc Deutsch B1: daily prep

A 105-day study plan for the telc Deutsch B1 exam (25 February 2027): one page per day with lesson, vocabulary, practice, Lesen, Sprachbausteine, Hören, Schreiben and Sprechen, an answer key, audio, weekly mock exams and a progress dashboard.

**Open the site:** https://lnmk970.github.io/Telc_B1_Prep/

The site files live in the [docs](docs) folder (one folder per day, plus the dashboard and the offline-app files).
